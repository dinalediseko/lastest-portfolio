Project Detail

Whole Number
Division

A robust division calculator reimagined with a tactile Neumorphism UI.

About the Project

This project began as a simple exercise in form validation and whole‑number division. After the logic was rock‑solid, I gave it a complete visual overhaul using the Neumorphism design trend. The result is a calculator that feels like a physical object—raised cards, sunken input fields, and a button that depresses on click.

All the original functionality remains: strict input checks, clear error messages, console logging, and whole‑number output. The transformation was purely cosmetic, proving that a single‑purpose tool can still be beautiful and engaging.

The interface is built with CSS box‑shadows on a soft `#ecf0f3` background. No external libraries were used for the design—every shadow, inset, and glow is hand‑crafted. The orange accent is used sparingly to highlight interactive elements without breaking the calm, tactile atmosphere.

Key Features

  • Neumorphism UI with raised/sunken elements
  • Zero, empty, and non‑numeric input validation
  • Automatic decimal flooring (e.g., 7 ÷ 3 = 2)
  • Console‑error logging for developers
  • Fade‑in animation on result display
  • Full‑screen critical error overlay with reload prompt
"A perfect example of how form and function can coexist. The neumorphic touch turns a mundane calculator into a memorable interaction."
