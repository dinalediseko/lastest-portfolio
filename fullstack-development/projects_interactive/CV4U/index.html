Certified

A glassmorphism‑styled, client‑side certificate generator with live preview and bulk CSV export.

About the Project

Certified was built to solve the repetitive task of creating personalised certificates for events, courses, and achievements. Instead of editing each document manually, users can drop a CSV, upload their logos, and receive a perfectly formatted multi‑page PDF in seconds.

The interface uses a modern glassmorphism aesthetic – frosted panels, subtle transparency, and vibrant gradients – making the tool enjoyable to use. Behind the scenes, html2canvas captures the styled certificate container, and jsPDF compiles the canvases into a high‑resolution, print‑ready document. The entire process runs locally; no data is ever uploaded.

The certificate template is fully customisable: organisation name, achievement title, student name, ID, and two logo slots. This makes it adaptable for any brand or purpose. The bulk CSV feature handles hundreds of recipients in one click.

Key Features

  • Glassmorphism UI with live preview
  • Editable organisation name and achievement/module
  • Upload two custom logos for branding
  • Bulk PDF generation from a simple CSV (Name, ID)
  • Print‑ready output at 1123×794px, scaled 2x
  • Fully client‑side, no sign‑up, works offline
