D'SEIKOU Business Site

A multi-page, responsive static website for the D'SEIKOU creative brand and its services.

About the Project

This website was built to serve as the primary online hub for D'SEIKOU, a multimedia design studio. The goal was to unify diverse services—from branding and web development to custom sneakers—under one bold, rebellious identity. It needed to be professional, easy to navigate, and drive client inquiries.

Using a Bootstrap template as a foundation, I transformed the design into a unique brand experience. The site features a sticky header, animated project carousel, tabbed process breakdown, and skill bars. Multiple call-to-action points (WhatsApp, email, phone, Google Forms) are integrated to maximise lead capture.

A key challenge was maintaining a fast, lightweight site while including numerous interactive elements. This was solved by lazy-loading images, using only the necessary JavaScript, and keeping CSS custom properties for easy theming.

Key Features

  • Multi-page structure (Home, About, Projects, Contact)
  • Owl Carousel for project showcases
  • Interactive process tabs (Discovery → Delivery)
  • Animated skill bars on About page
  • Sticky navigation and pre-header with social icons
  • Preloader for polished loading experience
  • Fully responsive (mobile hamburger menu)
  • Multiple CTAs (WhatsApp, phone, email, free quote form)
